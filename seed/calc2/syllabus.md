## How to write your work

Use Leibniz notation: if $y$ depends on $x$, write $\frac{dy}{dx}$. Carry the differential on every integral. Use $C$ for an arbitrary constant, and state intervals where a root or denominator restricts the answer. When a substitution introduces an angle, always call it $\theta$.

Name each identity you use. In Unit 3, label the five steps, write the differential on its own line, and draw the reference triangle before converting back. A final answer alone does not show which method you used.
